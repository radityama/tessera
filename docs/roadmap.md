# Roadmap

This is directional, not a release promise.

## v0.1 — Retrieval foundation

- canonical component schema,
- curated multi-library registry,
- deterministic search and ranking,
- score explanations,
- CLI,
- MCP server,
- Tessera agent skill,
- registry explorer,
- docs,
- safe installation guidance.

## v0.2 — Better discovery

Possible work:

- richer taxonomy,
- improved query parsing,
- semantic search,
- source refresh tooling,
- more libraries,
- registry snapshot distribution,
- project-aware search context.

## v0.3 — Visual retrieval

Possible work:

- component screenshot indexing,
- visual similarity,
- screenshot-to-component matching,
- design-language matching,
- richer preview metadata.

## v0.4 — Adaptation intelligence

Possible work:

- design token extraction,
- adaptation plans,
- dependency normalization,
- automated style normalization suggestions,
- page-level cohesion scoring.

## v0.5 — Agent-native composition

Possible work:

- page intent planning,
- multi-component compatibility scoring,
- composition recommendations,
- conflict detection across selected components,
- project-specific memory of design decisions.

## Anti-roadmap

Do not prioritize these before retrieval quality works:

- marketplace,
- billing,
- team dashboard,
- hosted accounts,
- giant crawler fleet,
- proprietary model training,
- Figma plugin,
- arbitrary code execution.
